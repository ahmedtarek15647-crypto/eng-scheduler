# 🏗️ EngScheduler Pro

Automated engineering project intake, critical path scheduling (WBS), and cash flow milestone planner designed for desktop, laptop, and mobile devices.

---

## 🚀 Quick Start (Local Run)

1. Open your terminal in this directory:
   ```bash
   cd engineering_scheduler
   ```
2. Run the application:
   ```bash
   python -m streamlit run app.py
   ```
3. Your browser will automatically open at `http://localhost:8501`.
   - **Local Network Mobile Access:** To test on your mobile phone on the same Wi-Fi, open the **Network URL** displayed in your terminal (e.g. `http://192.168.1.X:8501`).

---

## ☁️ How to Open Anywhere, Anytime (Free Cloud Hosting)

To access this from anywhere on your phone without leaving your PC running:

1. Create a free account at [GitHub](https://github.com) and push this `engineering_scheduler` folder to a private or public repository.
2. Go to [share.streamlit.io](https://share.streamlit.io) (Free Streamlit Community Cloud).
3. Connect your GitHub repository and select `app.py` as the main file path.
4. Click **Deploy**.
5. You will get a permanent public link:
   ```
   https://<your-app-name>.streamlit.app
   ```
6. **Open that link on your phone** and tap **"Add to Home Screen"** (iOS Safari or Android Chrome) to use it just like a native mobile app!
